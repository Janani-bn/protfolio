# Janani B N — Portfolio

Personal portfolio website showcasing projects, skills, experience, and achievements.

## Tech Stack

- **HTML5** — semantic markup and accessible structure
- **CSS3** — custom properties, responsive grid layout, animations
- **JavaScript** — smooth scrolling, nav toggle, scroll-to-top, intersection observers

No frameworks or build tools — just static files served directly.

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Janani-bn/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in a browser, or start a local server:

   ```bash
   # Python
   python3 -m http.server 8000

   # Node.js (npx, no install needed)
   npx serve .
   ```

3. Visit `http://localhost:8000` (or the port shown in your terminal).

## Project Structure

```
index.html   — page content and layout
styles.css   — all styling
script.js    — interactivity (nav, scroll, animations)
```
